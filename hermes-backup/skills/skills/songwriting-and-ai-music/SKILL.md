# Songwriting & AI Music Generation Skill

歌曲创作技法与 AI 音乐生成提示词工程，以 Suno 为主。

## 歌曲结构

```
ABABCB  — Verse/Chorus/Verse/Chorus/Bridge/Chorus (流行)
AABA    — Verse/Verse/Bridge/Verse (爵士/民谣)
AAA     — Verse/Verse/Verse (民谣/叙事)
```

六个组成块：Intro / Verse / Pre-Chorus / Chorus / Bridge / Outro

## 韵律类型

- 完美韵：lean/mean
- 家族韵：crate/braid
- 谐音韵：had/glass（相同元音）
- 辅音韵：scene/when

## Suno 提示词公式

**Style 字段**（ Genre + Mood + Era + Instruments + Vocal Style + Production + Dynamics）：

```
BAD: "sad rock song"
GOOD: "Cinematic orchestral spy thriller, 1960s Cold War era,
       smoky sultry female vocalist, big band jazz, brass
       section, minor key, vintage analog warmth"
```

**描述旅程，不只是类型**：
```
"Begins as a haunting whisper over sparse piano. Gradually
 layers in muted brass. Builds through the chorus with full
 orchestra. Second verse erupts with raw belting intensity.
 Outro strips back to a lone piano."
```

## 元标签

- 结构：[Intro] [Verse] [Chorus] [Bridge] [Outro]
- 动态：[Building Energy] [Explosive] [Gradual swell]
- 人声：[Whispered] [Belted] [Soulful] [Harmonies]
