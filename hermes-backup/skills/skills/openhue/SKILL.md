# OpenHue Skill

通过 OpenHue CLI 控制 Philips Hue 灯泡、房间和场景。

## 核心功能

- **灯光控制**：开/关/调亮度/色温/RGB 颜色
- **场景管理**：预设场景切换
- **Hue Entertainment**：低延迟同步（游戏/影视场景）
- **房间控制**：按房间批量控制

## 依赖

- Philips Hue Bridge 设备（在同一网络）
- OpenHue CLI 工具

## 使用前提

需要 Hue Bridge 硬件和 Hue 账号配置。没有 Hue 系统此 skill 完全无用。
