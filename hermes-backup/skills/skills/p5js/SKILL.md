# p5.js Creative Coding Skill

用 p5.js 创建浏览器交互式和生成式视觉艺术。

## 核心功能

- 2D / 3D 渲染
- 噪声和粒子系统
- 流场
- GLSL 着色器
- 像素操作
- 运动字体
- WebGL 场景
- 音频分析
- 鼠标/键盘交互
- 无头模式高分辨率导出

## 输出格式

HTML / PNG / GIF / MP4 / SVG

## 使用

当用户请求 p5.js sketch、生成艺术、交互可视化、Canvas 动画时触发。

## 技术栈

- p5.js
- 原生 JavaScript
- GLSL 着色器
- Web Audio API
