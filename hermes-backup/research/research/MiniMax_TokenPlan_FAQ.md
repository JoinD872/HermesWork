# MiniMax Token Plan — 常见问题
> 来源：https://platform.minimaxi.com/docs/token-plan/faq

---

## 📌 核心说明

**Token Plan 支持 MiniMax 全模态模型**：文本、语音、视频、图像、音乐。
- 文本模型（M2.7）：所有套餐均可使用
- 非文本模型：根据套餐等级开放不同权限和每日配额
- 极速版额外支持 `MiniMax-M2.7-highspeed` 和 `MiniMax-M2.5-highspeed`

---

## 🔑 模型列表

| 类型 | 模型 |
|------|------|
| **文本** | MiniMax-M2.7、MiniMax-M2.5 |
| **高速文本** | MiniMax-M2.7-highspeed、MiniMax-M2.5-highspeed（极速版专享） |
| **TTS HD** | speech-2.8-hd、speech-2.6-hd、speech-02-hd |

| **图像** | image-01 |

切换模型：修改 API 调用时 `model` 参数即可。

## 📊 用量重置机制

| 模型类型 | 重置机制 |
|----------|----------|
| **文本模型（M2.7）** | 5 小时滚动窗口，过去 5 小时请求总量超限后自动释放 |
| **非文本模型**（TTS/视频/音乐/图像） | 每日配额，每日自动重置 |

**查看用量方式：**
1. 订阅管理页面
2. API 接口：
```bash
curl --location 'https://www.minimaxi.com/v1/token_plan/remains' \
--header 'Authorization: Bearer <API Key>' \
--header 'Content-Type: application/json'
```

## ⬆️ 升级与退款

- **升级**：订阅期内随时可升，包括标准版→极速版、同版本内升等级。支付差价后立即生效。
- **退款**：不支持退款，一经购买即确认。建议按需选择套餐和周期。

## 💳 额度与限制

### 达到限额怎么办？
**文本模型限流时：**
1. 升级套餐
2. 切换为普通 API Key（按量付费，消耗账户余额）
3. 等待 5 小时窗口滚动自动恢复

**非文本模型超每日配额：**
1. 升级套餐
2. 切换为普通 API Key
3. 等待次日自动重置

### ⚠️ Token Plan API Key vs 普通 API Key
| | Token Plan API Key | 普通 API Key |
|--|--|--|
| 计费方式 | 文本按请求数（5h滚动限额）、非文本按日配额 | 按实际 token 消耗量 |
| 账户余额 | 不消耗 | 消耗余额 |
| 全模态访问 | ✅ | ✅ |

**两者不可混用。**

## ⚡ 平台流量规则（动态限流）

### 实施原因
超高并发自动化批量任务/多用户共享挤占算力，MiniMax 实施动态限流保障公平性。

### 规则
- **流量高峰**：工作日 15:00–17:30（根据集群负载动态调整）
- **各套餐持续调用支持**：
  - Starter / Plus：约 1 个 Agent
  - Max：约 2 个 Agent
  - Ultra：约 4 个 Agent
- **周额度限制**：
  - 2026-03-22 23:59:59 前购买：不受周额度限制
  - 2026-03-23 00:00:00 起购买：周额度 = 「5小时额度」× 10 倍

### 是否适合生产环境？
> Token Plan 面向**个人开发者的交互式使用场景**。生产环境建议使用 **Pay as you go**。

主要限制：
- RPM / TPM 速率限制（超出后约1分钟恢复，高峰期动态收紧）
- 文本模型 5 小时滚动窗口请求上限
- 非文本模型每日配额

## 🔧 OpenClaw 接入 M2.7

由于 OpenClaw 近期更新较慢，需手动配置：

1. 打开配置文件：`~/.openclaw/openclaw.json`
2. 将文件中所有 `M2.5` 全局替换为 `M2.7`
3. 执行：`openclaw gateway start`
