# 逆向纯净环境执行规则

> 适用范围：`E:\Opencode\MXD\逆向_纯净`

开始工作前先阅读上级 [`AGENTS.md`](../AGENTS.md) 和本目录的 [`WORK_RULES.md`](WORK_RULES.md)。本文件只补充逆向纯净环境的局部约束。

## 1. 纯净边界

- 本目录只接受离线逆向分析、静态证据整理和与逆向直接相关的报告。
- 原始 dump、metadata、资源包和已有证据默认只读，不覆盖、不重写、不删除。
- 纠正已有结论时追加新报告，保留原始文件和历史链路。
- 禁止写入 Bot 代码、运行配置、外部挂机日志、调试截图和无关备份。
- 不读取运行中的游戏进程内存，不注入，不发包，不模拟真实输入。

## 2. 分析与验证边界

- 超过 100MB 的文件必须搜索定位、流式处理或分块读取，禁止整文件载入内存。
- 重型分析必须记录输入文件身份、进程、内存和清理结果。
- NonFinite/AntiMacro 的结论必须区分 `CONFIRMED`、`STRONG_INFERENCE` 和 `UNKNOWN`。
- 离线练习、Shader 预览和数据对拍不能被描述为真实游戏成功判定。
- 涉及进程、驱动、注入或发包的请求默认停止，先明确安全范围、证据目标和回滚方式。

## 3. 产出要求

每份分析产出都要说明：

```text
输入文件和版本
使用的方法
证据位置
结论可靠性
仍然未知的内容
下一步建议
```

提交前检查本轮是否只包含逆向产出，是否保留了原始数据，以及验证证据是否对应同一个提交版本。
