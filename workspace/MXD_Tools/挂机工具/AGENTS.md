# 挂机工具执行规则

> 适用范围：`E:\Opencode\MXD\挂机工具`

开始工作前先阅读上级 [`AGENTS.md`](../AGENTS.md) 和本目录的 [`WORK_RULES.md`](WORK_RULES.md)。本文件只补充挂机工具的局部约束；与上级规则冲突时，以更具体的安全约束为准。

## 1. 代码修改边界

- 生产代码只修改本目录内与本轮目标直接相关的文件。
- `逆向_纯净`只能读取，不能写入 Bot 代码、配置、日志或调试产物。
- 不得为了修一个功能顺便重构地图识别、YOLO、WorldRoute、状态机或 UI。
- 涉及状态机、导航、输入授权、断线重连或安全停止时，至少按 L2 任务处理，必须有明确任务边界和验收标准。
- 任何输入输出路径、权限校验、`dry_run`、`SAFE_STOP` 和人工接管逻辑的修改，都必须说明潜在绕过路径。

## 2. 验证要求

代码修改后至少完成与目标匹配的验证：

- Python 文件：运行对应的 `py_compile` 或等价语法检查；
- 逻辑修改：运行相关单元测试或离线回放；
- 导航、抓绳、跳跃、Portal、断线重连：尽可能补充真实运行日志或录屏；
- 安全边界修改：验证停止、取消、超时和异常路径；
- 提交前检查差异、修改文件和提交号。

不能只用“测试通过”作为证据，必须写明测试对象、环境、结果和对应提交号。

## 3. 安全边界

- 不读取游戏进程内存，不进行 DLL 注入，不伪造网络结果。
- AntiMacro/NonFinite 触发时，优先停止自动输入、暂停导航和攻击、记录证据并报警。
- 不把杀进程、自动重连或修改成功/失败标志描述为可靠的规避方案。
- 不结束游戏、反作弊、Codex 或其他不属于本轮的进程来清理资源。
